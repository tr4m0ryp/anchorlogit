% section: abstract
\begin{abstract}
scikit-learn's \code{LogisticRegression} cannot take a per-sample offset (a fixed term added to each example's log-odds), so a known reference probability can only enter as a feature.
We add \code{offset=} to \code{fit} and every prediction method, and a package that uses a cross-validated fraction $\kappa$ of the reference's log-odds as the offset.
Against pristine scikit-learn \nVerSklearn{} \code{LogisticRegressionCV} without the reference, test log-loss changes by \nHgTwoFiftyDKcvPlain{} (SE \nHgTwoFiftyDKcvPlainSe) on HIGGS and \nBkTwoFiftyDKcvPlain{} (SE \nBkTwoFiftyDKcvPlainSe) on Bank Marketing at \nSizeTwoFifty{} training rows, but not on the drifting Elec2 stream.
Against the reference as a nearly unpenalised feature it ties, winning beyond \nWinK{} SE in \nBeatKcvFree{} of \nMainCells{} cells (HIGGS, $n = \nSizeOneK$: \nHgOneKDKcvFree, SE \nHgOneKDKcvFreeSe).
The one kept variant, a one-SE rule toward $\kappa = 1$, beat that feature under the same rule on fresh draws at $n = \nSizeHund$ (\nCfHundDFreeRule, SE \nCfHundDFreeRuleSe), not at $n = \nSizeHundFifty$, and never beat the reference alone.
SEs are between disjoint repeats of paired held-out differences; fits match statsmodels and glum to \nTwinGlumCoef.
\end{abstract}

% section: 1
\section{Problem}
\label{sec:problem}

An offset is a known term added to the linear score of a generalised linear model (GLM)~\citep{mccullagh1989}.
The model learns weights for the features, but the offset keeps its coefficient fixed at one.
R's \code{glm}, glmnet~\citep{friedman2010}, statsmodels~\citep{seabold2010} and glum~\citep{glum} all accept it.
scikit-learn~\citep{pedregosa2011} does not, and the request to add it is still an open issue on the project's tracker~\citep{sklearn24614}.

The case we care about is a strong reference: every example already has a probability from an older model, other data or an outside source.
A ridge logistic model on a few hundred rows should then learn only the correction that the features add.
Without an offset the reference's log-odds must go in as one more column, and the ridge shrinks the coefficient of the strongest input in the model.
Scaling that column up makes its coefficient nearly free, which removes the shrinkage but also any pull toward one.
The change came out of a private application, and Appendix~\ref{app:origin} gives the one result we report from it.
Everything else is measured on public benchmarks.

% section: 2
\section{The change}
\label{sec:change}

We add an array \code{offset} of shape $(n,)$ to \code{fit}, \code{decision\_function}, \code{predict}, \code{predict\_proba} and \code{predict\_log\_proba}, in the same way as \code{sample\_weight}.
The model and its objective are
\begin{equation}
\eta_i = x_i^\top w + b + o_i,
\qquad
\min_{w,b}\; C \sum_{i=1}^{n} s_i\, \ell(y_i, \eta_i) + \tfrac{1}{2}\lVert w\rVert^2 ,
\label{eq:offset}
\end{equation}
where $\eta_i$ is the log-odds of example $i$, $o_i$ its given (not fitted) offset, $s_i$ its sample weight, $C$ the inverse ridge strength and $\ell(y,\eta) = \log(1+e^{\eta}) - y\eta$ the log-loss.
The offset is data: it is never stored, and $o = \code{None}$ gives the current behaviour bit for bit.
Our library diff is \nPatchLibAdd{} added and \nPatchLibDel{} removed lines, with \nPatchTestAdd{} lines of tests.
One removed line fixes a bug the offset exposed: the Newton line search evaluates $\eta(w + t\,d) = \eta(w) + t\,X d$, but built $X d$ with the helper that adds $o$, so the offset counted twice per step and newton-cholesky stalled.

Our package \code{anchorlogit} builds the offset from a reference probability $p_i$, with $r_i = \operatorname{logit}(p_i)$:
\begin{equation}
o_i = \kappa\, r_i, \qquad \kappa \in \{\nKappaGrid\},
\label{eq:kappa}
\end{equation}
where $\kappa$ is the fraction of the reference we trust, chosen jointly with $C$ by $\nFolds$-fold cross-validated log-loss.
$\kappa = 1$ is the classical GLM offset and $\kappa = 0$ ignores the reference.
For training rows the reference must be out of sample: if it was fitted on the same rows, \code{anchorlogit} cross-fits it (each row gets a prediction from a fit that did not see it)~\citep{chernozhukov2018}.

The recipe needs nothing specific to a domain: (i) For every example, training and new, get a reference probability $p_i$ from a source that did not see that example's label, and clip it away from 0 and 1.
(ii) Compute $r_i = \operatorname{logit}(p_i)$.
(iii) Fit on the training rows with \code{offset}$= \kappa r$ for each $(\kappa, C)$ on the grid, and keep the pair with the lowest cross-validated log-loss.
(iv) At prediction time pass \code{offset}$= \kappa r$ for the new rows as well; the model returns the corrected log-odds.
In the package, \code{AnchoredLogisticRegression(anchor=j, kappa="cv")} takes $p$ as column \code{j} of $X$ and does (ii) to (iv), with $C$ tuned by any scikit-learn grid search; given an unfitted classifier as \code{anchor}, it also does (i) by cross-fitting.

A general form lets the coefficient on $r$ move but pulls it toward $\kappa$, with an anchoring strength $\lambda$:
\begin{equation}
J(w,b,\beta) = C \sum_{i} s_i\, \ell\bigl(y_i,\; x_i^\top w + b + \beta r_i\bigr) + \tfrac{1}{2}\lVert w\rVert^2 + \tfrac{1}{2}\lambda(\beta-\kappa)^2 .
\label{eq:anchored}
\end{equation}
$\lambda = \infty$ is the fixed offset of Equation~\ref{eq:kappa} and $\lambda = 0$ is the reference as a free column.
Lemma~\ref{lem:anchored} shows that every $\lambda$ in between needs nothing beyond \code{offset=}.

\begin{lemma}\label{lem:anchored}
For $0 < \lambda < \infty$, $(w^*, b^*, u^*)$ minimises the offset problem~\eqref{eq:offset} with offset $o_i = \kappa r_i$ and one extra ridge column $r_i/\sqrt{\lambda}$ (weight $u$) if and only if $(w^*, b^*, \kappa + u^*/\sqrt{\lambda})$ minimises $J$.
\end{lemma}
The proof is in Appendix~\ref{app:proof}; the check in code matches the direct minimisation of $J$ to \nTwinLemTwoEta{} in $\eta$ over \nTwinLemTwoCases{} cases.

% section: 3
\section{Setup}
\label{sec:setup}

We use three public datasets from OpenML~\citep{vanschoren2014}, each with a different kind of reference.
\textbf{HIGGS}~\citep{baldi2014}: gradient boosting on the \nHgLowCols{} low-level columns, fitted once on \nHgRefRows{} disjoint rows, is the reference; the ridge sees all \nHgAllCols{} columns, so the features partly re-express it.
\textbf{Bank Marketing}~\citep{moro2014}: gradient boosting on every column, fitted on a disjoint half, so the features add nothing (the expected null).
\textbf{Elec2}~\citep{harries1999}: a time-ordered stream; the reference is fitted on rows before each origin with an embargo (a gap of left-out rows) of \nElEmbargo{} rows, so it ages, and the test set is the next week.
Within a repeat every arm sees the same training rows, the same features and the same folds; only the use of $r$ differs.
HIGGS has \nHgRepeats{} repeats, Bank \nBkRepeats{} and Elec2 \nElRepeats{}; each repeat is a disjoint (train, test) draw with \nHgTestPerRep, \nBkTestPerRep{} and \nElTestPerRep{} test rows.

\bottomrule
\end{tabular}

$C$ runs over \nCGridSize{} values from \nCGridLo{} to \nCGridHi.
The metric is test log-loss in nats (natural-log units). For arm $a$ against ours, repeat $j$ of $R$ gives the paired difference over its test rows $T_j$:
\begin{equation}
d_j = \frac{1}{|T_j|}\sum_{i \in T_j} \bigl[\ell(y_i, \eta^{\mathrm{ours}}_i) - \ell(y_i, \eta^{a}_i)\bigr],
\qquad
\bar d = \frac{1}{R}\sum_{j=1}^{R} d_j,
\qquad
\mathrm{SE} = \frac{\operatorname{sd}(d_1,\dots,d_R)}{\sqrt{R}} .
\label{eq:paired}
\end{equation}
Negative $\bar d$ favours ours. Because the repeats are disjoint, this SE includes the noise of the training draw.
We call it a win only when $|\bar d| > \nWinK\,\mathrm{SE}$, and anything inside that is a tie.
We fixed \nPreregChecks{} checks before the runs: a6 beats a1 on most of the \nDatasets{} datasets, a6 versus a3 and a4, and $\kappa_{\mathrm{cv}} < 1$ where the reference is off.

To find what would make the offset win, we tried \nPostHocVariants{} post-hoc variants and kept only the first.
At $n = \nSizeHund$ the CV minimum over $\kappa$ was noisy, and $\kappa_{\mathrm{cv}}$ lost to $\kappa = 1$ (\nHsHundDKcvKOne, SE \nHsHundDKcvKOneSe).
The one-SE rule~\citep{hastie2009} takes, among all $(\kappa, C)$ within one fold-SE of the best cross-validated loss, the largest $\kappa$ and then the strongest ridge:
\begin{equation}
(\hat\kappa, \hat C) = \operatorname*{arg\,max}_{(\kappa, C) \in S}\, (\kappa, -C),
\qquad
S = \{(\kappa, C) : \mathrm{CV}(\kappa, C) \le \mathrm{CV}_{\min} + \mathrm{SE}_{\min}\},
\label{eq:onese}
\end{equation}
where the arg max is lexicographic (compare $\kappa$ first, then $C$) and $\mathrm{SE}_{\min}$ is the fold SE at the CV minimum.
To keep the comparison fair, the free column gets the same $C$ rule as a control.
Figure~\ref{fig:paired}(d) shows the result and Table~\ref{tab:onese} in Appendix~\ref{app:checks} lists it.


On the draws it was chosen on, the rule beats the free column under its own $C$ rule at $n = \nSizeHundFifty$ (\nHcHundFiftyDRuleFreeRule, SE \nHcHundFiftyDRuleFreeRuleSe), and at $n = \nSizeHund$ it is just inside \nWinK{} SE (\nHcHundDRuleFreeRule, SE \nHcHundDRuleFreeRuleSe).
Because it was chosen after seeing those numbers, we reran it on \nCfRepeats{} fresh HIGGS draws whose rows none of the variant runs used.
There the order flips: a win at $n = \nSizeHund$ (\nCfHundDFreeRule, SE \nCfHundDFreeRuleSe) and a tie at $n = \nSizeHundFifty$ (\nCfHundFiftyDFreeRule, SE \nCfHundFiftyDFreeRuleSe).
It loses to the reference alone at every $n \le \nSizeTwoFifty$, on the fresh draws too.
Because it selects $\kappa = 1$ in every draw, this rule amounts to the classical offset with a conservative ridge, not a fractional one.

A reference built from all \nHgAllCols{} HIGGS columns, which the features only re-express, gave a tie with the free column (\nSrHundDKcvFree, SE \nSrHundDKcvFreeSe, $n = \nSizeHund$) and a loss to the reference alone.
A Bank reference trained only on younger clients, wrong in a group the features can see, is where the fraction pays: $\kappa_{\mathrm{cv}}$ has median \nBsOneKKcvKappaMed{} and beats $\kappa = 1$ by \nBsOneKDKcvKOne{} (SE \nBsOneKDKcvKOneSe) at $n = \nSizeOneK$.
It still ties the free column (\nBsOneKDKcvFree, SE \nBsOneKDKcvFreeSe) and the Platt-recalibrated reference.

Appendix~\ref{app:checks} gives the ablations and equivalence checks.
Calibration tells the same story: in Figure~\ref{fig:rel} the expected calibration error (ECE, mean gap between predicted and observed frequency) of the offset and of the free column are close.

\section{Limits}
\label{sec:limits}

The headline is a tie: the offset beats the nearly free column in \nBeatKcvFree{} of \nMainCells{} cells (\nBeatKcvFreeBoot{} under a two-stage bootstrap SE that resamples repeats, then test rows), so scaling one column gets most of the gain.

On Elec2 the offset does not beat the model without the reference (\nElTwoFiftyDKcvPlain, SE \nElTwoFiftyDKcvPlainSe); the Platt-recalibrated reference reaches \nElTwoFiftyPlattLL{} against its \nElTwoFiftyKcvLL{} at $n = \nSizeTwoFifty$ (\nElTwoFiftyDKcvPlatt, SE \nElTwoFiftyDKcvPlattSe, a tie only by the large SE), so $\kappa < 1$ is a coarse fix for a reference wrong in slope and level.

We ran \nMainArms{} main arms and \nVariantArms{} variant arms over \nResultFiles{} result files.
Of the \nPreregChecks{} pre-registered checks only the win over a1 on Elec2 failed, and a6 tied a3 at $n \ge \nSizeOneK$.
The \nPostHocVariants{} variants were post-hoc, and the kept one held on fresh draws at one of two sizes, by about \nWinK{} SE: weak evidence at best.
ACS Income, $n > \nSizeTwoK$ and more repeats were cut for budget.
The method is binary only; we claim nothing for the Poisson, Gamma and Tweedie regressors beyond the patch's tests.

\section{Proof of Lemma~\ref{lem:anchored}}
\label{app:proof}

\begin{proof}[Proof of Lemma~\ref{lem:anchored}]
Given:
\begin{enumerate}
\item $J$ as in~\eqref{eq:anchored};
\item the offset problem with the extra column, $K(w,b,u) = C\sum_i s_i\,\ell\bigl(y_i,\, x_i^\top w + b + u\,r_i/\sqrt{\lambda} + \kappa r_i\bigr) + \tfrac{1}{2}\lVert w\rVert^2 + \tfrac{1}{2}u^2$;
\item if $\phi$ is a bijection and $K(v) = J(\phi(v))$ for all $v$, then $v^*$ minimises $K$ if and only if $\phi(v^*)$ minimises $J$.
\end{enumerate}

\textbf{Choose:} $\phi(w,b,u) = (w,\, b,\, \kappa + u/\sqrt{\lambda})$, so $\beta = \kappa + u/\sqrt{\lambda}$.

\textbf{Need to prove:} $J(w, b, \kappa + u/\sqrt{\lambda}) = K(w,b,u)$ for all $(w,b,u)$.
The ridge term $\tfrac{1}{2}\lVert w\rVert^2$ is the same in both. The score term:
\begin{align*}
\beta r_i &= \bigl(\kappa + u/\sqrt{\lambda}\bigr) r_i && \text{substitution of } \beta\\
          &= \kappa r_i + u\,\bigl(r_i/\sqrt{\lambda}\bigr) && \text{distributive law}
\end{align*}
The anchoring term:
\begin{align*}
\tfrac{1}{2}\lambda(\beta-\kappa)^2 &= \tfrac{1}{2}\lambda\bigl(u/\sqrt{\lambda}\bigr)^2 && \text{substitution of } \beta\\
                                   &= \tfrac{1}{2}\lambda\, u^2/\lambda && \text{power of a quotient}\\
                                   &= \tfrac{1}{2}u^2 && \text{cancellation, } \lambda \neq 0
\end{align*}
\textbf{Substitution} of both pieces into $J$, with the same ridge term, gives:
\begin{align*}
J(w, b, \kappa + u/\sqrt{\lambda}) &= C\sum_i s_i\,\ell\bigl(y_i,\, x_i^\top w + b + u\,r_i/\sqrt{\lambda} + \kappa r_i\bigr) && \text{both pieces}\\
                                   &\quad + \tfrac{1}{2}\lVert w\rVert^2 + \tfrac{1}{2}u^2 \\
                                   &= K(w, b, u) && \text{definition of } K
\end{align*}
\textbf{Precondition:} rule 3 is only valid if $\phi$ is a bijection, therefore its inverse must exist on all of $\mathbb{R}$:
\begin{align*}
\beta = \kappa + u/\sqrt{\lambda} \;&\Longleftrightarrow\; \beta - \kappa = u/\sqrt{\lambda} && \text{subtract } \kappa\\
                                    &\Longleftrightarrow\; u = \sqrt{\lambda}\,(\beta - \kappa) && \text{multiply by } \sqrt{\lambda},\ 0 < \lambda < \infty
\end{align*}
Every $\beta \in \mathbb{R}$ has exactly one such $u$, and $w$ and $b$ map to themselves, so $\phi$ is a bijection.

\textbf{Therefore,} by rule 3: $(w^*,b^*,u^*)$ minimises $K$ if and only if $(w^*, b^*, \kappa + u^*/\sqrt{\lambda})$ minimises $J$.
\end{proof}

\section{Reproduction}
\label{app:repro}

All code and results are at commit \code{\nCommit} of the \code{anchorlogit} repository. The patch is \code{patches/scikit-learn-offset.patch} (its full diff against scikit-learn \nVerSklearn); the benchmarks run with \code{bench/run\_all.sh} and \code{bench/run\_variants.sh}, and \code{python -m bench.summarize} prints every table.
The fresh-draw check of the one-SE rule is \code{python paper/results/confirm\_1se.py}. Numbers in this note come from \code{paper/results/make\_numbers.py} and \code{make\_extra.py}; recomputing the means and SEs from the stored per-row test log-odds differs from the result files by at most \nRecomputeMaxDiff.
All runs used CPU only with \nThreads{} threads per process, \nComputeHours{} h in total (HIGGS \nHgRuntimeMin{} min, Elec2 \nElRuntimeMin, Bank \nBkRuntimeMin), Python \nVerPython, scikit-learn \nVerSklearn, statsmodels \nVerStatsmodels, glum \nVerGlum, \code{anchorlogit} \nVerAnchorlogit.
On stock scikit-learn without the patch the package passes \nPkgTestsStockPass{} tests and skips \nPkgTestsStockSkip.
