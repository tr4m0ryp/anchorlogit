On a proprietary binary forecasting task with a strong external reference probability and a few hundred training examples, refitting a ridge logistic model with a fixed offset of 0.25 x the reference's log-odds lowered held-out log-loss on about a thousand examples from 0.320 to 0.306 relative to the same model without the offset (paired difference -0.014, moving-block bootstrap SE 0.0035). The fraction was not the best choice: the full offset (kappa = 1) reached 0.283 (0.25 minus 1: +0.023, SE 0.005) and the reference log-odds as an ordinary, nearly unpenalised feature reached 0.287 (offset 0.25 minus feature: +0.018, SE 0.006), the full offset and the free feature being within 0.004 (SE 0.002) of each other.
